# 月の形よみ（tsuki-katachi）

月の絵や空の場面を見て、月の名前・見える時刻と方角・昔の呼び名を当てる1日5問の学習ゲーム。正解したら「なぜそうなる？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/tsuki-katachi/>

- 中身は国立天文台 暦計算室の資料で確かめたことだけ（<https://eco.mtk.nao.ac.jp/koyomi/>）。見え方は日本（北半球）で、南を向いて見たときのものです。
- 時刻は平均の、およその値です。日や季節で前後します。このゲームは公式の情報の代わりではありません。その日の正しい月の出・月の入りは、国立天文台 暦計算室で確かめてください。
- 場面はすべて練習のために作ったものです。記録は遊ぶ人のブラウザだけに残り、外へ送りません。

作業の決まりは [AGENTS.md](AGENTS.md)。
